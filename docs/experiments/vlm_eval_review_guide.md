## 질의 두 종류 (결과도 따로 보고)

| 표시 | 만든 방법 |
|---|---|
| 「AI 초안」만 | AI가 영상 화면·자막을 보고 쓴 질의 (영상당 S 4·V 4·정답 없음 2, 말 없는 영상은 V 6·정답 없음 2) |
| 「사용자 질문 · 어르신」 등 | 별도 AI가 **영상 제목·채널·정책만 보고** 실제 사용자처럼 쓴 질문(영상당 3개). 영상 내용을 모르고 썼으니 영상에 답이 없을 수도 있습니다. 정답 구간(또는 정답 없음)은 다른 AI가 영상을 보고 초안을 만들었습니다 |

- 할 일은 두 종류 모두 같습니다: 구간을 재생해 보고 맞으면 「검수 완료」, 틀리면 「편집」으로 고친 뒤 「수정 저장 + 검수 완료」, 질의 자체가 이상하면 삭제.
- 사용자 질문은 **문구를 다듬지 마세요**(애매하거나 구어체인 게 의도입니다). 정답 구간과 유형(S/V/정답 없음)만 확인합니다. 정답이 있다고 됐는데 영상에 없으면 삭제만 해 주세요(정답 없음으로 옮기는 건 제가 정리합니다).
- 「미검수만 보기」로 남은 것만 걸러 볼 수 있습니다.

### 부분 답 규칙 (사용자 질문·AI 초안 공통)

- 질문에 **직접 쓸모 있는 정보**가 나오는 장면이면 **정답**으로 하고, 메모(note) 맨 앞에 **「부분」**이라고 적습니다.
  예: 「나도 받을 수 있는건가」에 나이 조건(만 65세)만 나오고 소득 기준은 없는 장면 → 정답, 메모 「부분: 나이 조건만 나옴」.
- **주제만 비슷하고** 질문에 쓸 정보가 없으면 **정답 없음**입니다.
  예: 「엄마 대신 인터넷으로 신청 되나요」에 본인이 신청하는 화면만 나옴 → 정답 없음.
- 초안이 정답이라고 했는데 주제만 비슷하면 그 질의를 삭제합니다(정답 없음으로 옮기는 건 제가 정리합니다). 초안이 정답 없음이라고 했는데 직접 쓸모 있는 장면이 있으면, 정답 없음 질의를 삭제하고 같은 문구로 새 질의를 만들어 구간을 찍어 주세요.

## 접속과 실행

라벨링 도구는 서버 안에서만(127.0.0.1) 열리므로, 내 컴퓨터에서는 **포트 포워딩**으로 접속합니다.

### 1) 서버에서 도구 실행

서버에 접속한 터미널에서 실행하고, 검수하는 동안 터미널을 닫지 않습니다.

    cd ~/scenefinder
    python tools/labeler/server.py --labels ai/experiments/vlm_model/labels/review.json \
        --youtube-list ai/experiments/vlm_model/labels/review_videos.tsv \
        --videos /nfs/team/data/scenefinder_vlm/eval_videos --port 8771

### 2-A) VS Code로 접속 (추천)

1. VS Code에서 Remote-SSH로 서버에 접속합니다(왼쪽 아래 `><` 아이콘 → Connect to Host).
2. 위 1)의 명령을 VS Code 터미널에서 실행합니다.
3. 아래 패널의 **PORTS(포트)** 탭 → **Forward a Port(포트 전달)** → `8771` 입력. 도구를 실행하면 자동으로 추가되기도 합니다.
4. 내 컴퓨터 브라우저에서 `http://127.0.0.1:8771`을 엽니다. PORTS 탭의 지구본 아이콘을 눌러도 됩니다.

### 2-B) ssh 명령으로 접속

내 컴퓨터 터미널(Windows는 PowerShell)에서 실행합니다. `<계정>`, `<서버주소>`는 평소 서버에 접속할 때 쓰는 값입니다.

    ssh -L 8771:127.0.0.1:8771 <계정>@<서버주소>

이 접속을 유지한 채 그 창에서 위 1)의 명령을 실행하고, 내 컴퓨터 브라우저에서 `http://127.0.0.1:8771`을 엽니다.

### 안 될 때

- 「address already in use」: 같은 포트로 도구가 이미 떠 있습니다. 떠 있는 도구를 쓰거나 끈 뒤 다시 실행합니다.
- 브라우저에서 연결 거부: 서버에서 도구가 실행 중인지, 포워딩한 포트와 도구의 `--port`가 같은지 확인합니다.
- 영상이 안 나옴: 영상 정보 칸의 재생 방식을 「로컬 파일」로 바꿉니다(망에서 YouTube 임베드가 막힌 경우).

### 사용할 때 알아 둘 것

- 처음에는 YouTube 임베드로 재생되고, 영상 정보 칸의 재생 방식에서 「로컬 파일」(서버에 받아 둔 720p mp4)로 바꿀 수 있습니다. 시간은 둘이 같습니다.
- 영상 키(dev01 등)는 이미 정해져 있으니 바꾸지 마세요.
- 저장할 때마다 서버의 파일에 바로 씁니다. 이전 내용은 `review.json.bak`에 남습니다.
- 서버 담당이 초안을 더 합치는 동안(test 초안 등)에는 도구를 끄고, 합친 뒤 다시 켜 주세요. 켜 둔 채로 저장하면 합친 내용을 덮어쓸 수 있습니다.

## 질의 유형

| 유형 | 뜻 | 확인 방법 |
|---|---|---|
| S 말로 설명됨 | 내레이션이 **말하는 내용**을 찾는 질의 (조건, 금액, 기간, 주의사항, 팁) | 화면을 안 보고 소리만 들어도 구간을 고를 수 있어야 함 |
| V 화면에만 보임 | **화면**을 봐야 찾을 수 있는 질의 (신청서 칸, 버튼, 메뉴 단계, 서류 목록, 팝업) | 신청서·버튼·서류 이름처럼 화면 글자로 찾을 수 있으면 「화면 글자로 찾을 수 있음」 체크 |
| 정답 없음 | 이 영상에 말로도 화면으로도 **없는** 내용 | 영상 전체를 봤을 때 정말 없으면 「검수 완료」 |

- **자막만 언급 구간**(V 질의만): 내레이션은 그 내용을 말하지만 화면에는 안 나오는 구간입니다. 예를 들어 1:10에 「구비서류를 첨부하세요」라고 말하지만 화면은 만화이고, 실제 서류 첨부 화면은 4:20에 나오는 경우 1:10 부근이 자막만 언급 구간입니다. 시작·끝을 찍고 「자막만 언급 구간 추가」를 누릅니다. 없으면 비워 둡니다.
- 정답 구간은 그 내용이 **이어서 나오는 전체**를 잡습니다. 같은 내용이 여러 번 나오면 구간을 여러 개 추가합니다(판정은 가장 많이 겹친 구간 기준).
- 말이 없는 영상(dev06, test02)은 S 질의가 없습니다.

## AI 초안에서 특히 볼 것

- 구간 경계: 시작·끝이 2초 넘게 어긋나면 고칩니다(`,` `.`로 0.1초씩 이동).
- S 질의가 실제로는 화면 묘사가 아닌지(소리만으로 찾을 수 있는지). 화면 묘사면 유형을 V로 바꿉니다.
- 정답 없음 질의가 실제로는 영상에 나오지 않는지.
- 메모(note)에 AI가 근거로 본 시트·자막 줄이 적혀 있습니다. 영상별 「먼저 볼 것」(Whisper 오인식, 애매한 경계, 구간이 두 개인 질의): [vlm_eval_review_notes.md](vlm_eval_review_notes.md)

## 시간

예상 시간은 검수 목록의 `예상_분` 열에 있습니다. 영상 길이의 0.6배(훑어보기)에, 정답 있는 질의 1개당 2분(자막만 언급 구간이 있으면 +1분)과 정답 없음 1개당 1분을 더해 계산했습니다.
