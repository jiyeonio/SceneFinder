### 해석

1. **처음 실험보다 모든 방식이 크게 낮습니다.** IoU ≥ 0.3 기준 가장 좋은 방식도 34%입니다. 영상이 1분 안팎에서 2:40~15분으로 길어져 후보 구간이 많아졌고, 무작위 기준선도 13%에서 3%로 떨어졌습니다. 처음 실험 수치는 짧은 영상 4개라 높게 나온 것으로 봐야 합니다.
2. **설명문 검색에 구간 확장(M1)을 붙인 방식이 가장 좋습니다.** 전체 IoU ≥ 0.3 기준 34%(31/90), IoU ≥ 0.5 기준 17%(15/90)로, S에서도 자막 검색(27%)보다 높습니다. 설명문 검색의 1위 구간은 2초(중앙값)인데 정답은 7초(중앙값)라, 위치가 맞아도 IoU가 낮게 나왔습니다. V에서 놓친 질의 중 19개는 1위 구간 중심이 정답 중심과 10초 안이었습니다. 처음 실험에서는 정답이 2~3초로 짧아 M1이 IoU ≥ 0.5를 낮췄지만, 이번에는 두 기준 모두 올랐습니다. M1은 미리 정한 세 규칙(M0·M1·M2) 중 결과를 보고 고른 것이라, 다른 평가셋에서 한 번 더 확인해야 합니다.
3. **자막 검색(d)은 S에서도 27%(8/30)로 처음 실험(100%)보다 크게 떨어졌습니다.** 틀린 경우는 같은 내용을 다른 시점에 말한 경우(조명 이야기는 87초, 켜는 장면은 309초), Whisper 오인식(「고추 REALLY」, 다른 경기 해설로 인식), 말 없는 450초를 한 문장으로 합친 자막(먹방 마지막 인사)이었습니다. 1위 자막 하나만 쓰는 지금 방식은 문장이 100~250개인 긴 영상에서 약합니다.
4. **융합 A·B는 설명문 검색 단독과 비슷합니다(18~20%).** 처음 실험처럼 자막 검색이 강하지 않아 합쳐도 크게 오르지 않았습니다. B에 구간 확장을 붙여도 29%로 설명문 검색 + 확장(34%)보다 낮습니다. 자막 점수가 이긴 질의에서 자막 1위가 틀린 경우가 많기 때문입니다.
5. **다국어 CLIP(c)은 IoU ≥ 0.5에서 11%로 설명문 검색(확장 전 7%)보다 높고**, 말 없는 영상 4개(27개 질의)에서 6개를 맞혀 설명문 검색 확장 전(1개)보다 좋았습니다(확장 후 7개). Moment-DETR(a)(b)는 1위 구간이 32초(중앙값)로 길어 7~8%에 그쳤습니다.
6. **화면 글자가 있는 V 질의에서 설명문 검색이 오히려 낮았습니다(확장 후 8/26, 글자 없음 13/34).** 다만 글자 있음 질의는 tofu_silent(7개)·airpods_fake(5개)처럼 화면 전체에 글자가 깔린 영상에 몰려 있어, 화면 글자의 효과와 영상의 난이도를 이 결과로는 나눌 수 없습니다.

**다음 단계:** 1위 하나가 아니라 상위 k개 안에 정답이 있는지(R@k)도 재고, 설명문 검색의 구간 길이 규칙을 따로 평가셋을 나눠 정하고, 정답 없음 질의 12개로 점수 임계값(결과 없음 판정)을 평가하는 것이 필요합니다.

## 재현 방법

프로젝트 루트에서, 영상 12개를 `~/scenefinder_eval/videos/<YouTube ID>.mp4`에 둔 상태로 실행합니다.

    OUT=~/scenefinder_eval/results_v2
    cp ~/scenefinder_eval/labels_draft.json $OUT/labels_snapshot.json
    python ai/experiments/translation_compare/captions.py --out $OUT --queries $OUT/labels_snapshot.json --variants qwen_incl --skip-batch-timing
    python ai/experiments/translation_compare/run.py --out $OUT --queries $OUT/labels_snapshot.json
    python ai/experiments/translation_compare/fusion.py --out $OUT
    python ai/experiments/translation_compare/make_report_v2.py --results $OUT --draft <검수 전 AI 초안.json>

- 영상·feature·설명문·결과 JSON은 저장소 밖(`~/scenefinder_eval/`)에 둡니다.
- 라벨만 바뀌었으면 captions.py는 다시 돌릴 필요가 없습니다(feature·자막·설명문은 결과 폴더에 캐시됨).
