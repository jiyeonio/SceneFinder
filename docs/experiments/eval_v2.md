# 평가셋 v2: 분석된 YouTube 영상 12개로 다시 잰 장면 검색 비교

서비스에서 분석했던 YouTube 영상 12개(2:40~15:01)로 만든 평가셋으로 번역 방식별 영상 검색, 자막 검색, VLM 설명문 검색, 자막+설명문 융합을 다시 비교했습니다. 처음 실험([translation_compare.md](translation_compare.md))은 1분 안팎 영상 4개·질의 20개였고, 이번에는 말 없는 영상·긴 영상을 포함해 질의 90개입니다.

정답 구간은 AI 초안을 사람이 검수하는 방식으로 만들었습니다. 아래 「라벨과 검수」에 검수 현황이 있습니다. **미검수 초안이 남아 있으면 그 질의의 결과는 참고용입니다.**

### 해석

수치는 8장 묶음 처리한 설명문 기준입니다(1장씩 처리와의 차이는 「설명문 1장씩 처리 → 8장 묶음 처리」 절).

1. **처음 실험보다 모든 방식이 크게 낮습니다.** IoU ≥ 0.3 기준 가장 좋은 방식도 32%입니다. 영상이 1분 안팎에서 2:40~15분으로 길어져 후보 구간이 많아졌고, 무작위 기준선도 13%에서 3%로 떨어졌습니다. 처음 실험 수치는 짧은 영상 4개라 높게 나온 것으로 봐야 합니다.
2. **설명문 검색에 구간 확장(M1, 탐색적)을 붙인 방식이 가장 좋습니다.** 전체 IoU ≥ 0.3 기준 32%(29/90), IoU ≥ 0.5 기준 18%(16/90)입니다. 설명문 검색의 1위 구간은 2초(중앙값)인데 정답은 대부분 그보다 길어, 위치가 맞아도 IoU가 낮게 나옵니다. 다만 M1은 결과를 본 뒤 추가한 것이라 dev에서 정하고 test에서 확인해야 합니다.
3. **자막 검색(d)은 S에서도 27%(8/30)로 처음 실험(100%)보다 크게 떨어졌습니다.** 틀린 경우는 같은 내용을 다른 시점에 말한 경우(조명 이야기는 87초, 켜는 장면은 309초), Whisper 오인식, 말 없는 450초를 한 문장으로 합친 자막(먹방 마지막 인사)이었습니다. Whisper를 large-v3-turbo로 바꾸면 43%로 오릅니다(「Whisper」 절).
4. **융합 A·B는 설명문 검색 단독(14%)과 비슷하거나 낮습니다(A 12%, B 16%).** 자막 검색이 강하지 않아 합쳐도 오르지 않았고, B에 구간 확장을 붙여도 24%로 설명문 검색 + 확장(32%)보다 낮습니다. 자막 점수가 이긴 질의에서 자막 1위가 틀린 경우가 많기 때문입니다.
5. **다국어 CLIP(c)은 IoU ≥ 0.5에서 11%로 설명문 검색(3%)보다 높고**, 말 없는 영상 4개(27개 질의)에서 6개를 맞혀 설명문 검색(1개)보다 좋았습니다(확장 후 7개). Moment-DETR(a)(b)는 1위 구간이 32초(중앙값)로 길어 7~8%에 그쳤습니다.
6. **화면 글자가 있는 V 질의에서 설명문 검색이 오히려 낮았습니다(확장 후 7/26, 글자 없음 13/34).** 다만 글자 있음 질의는 tofu_silent(7개)·airpods_fake(5개)처럼 화면 전체에 글자가 깔린 영상에 몰려 있어, 화면 글자의 효과와 영상의 난이도를 이 결과로는 나눌 수 없습니다.
7. **R@3·시작점 오차로 보면 '위치는 맞는데 1위·구간 길이가 틀린' 경우가 많습니다.** 설명문 검색(e)은 1위 IoU ≥ 0.3이 14%지만 R@3은 32%, 시작 ±5초는 31%입니다. 자막 검색(d)도 S에서 1위 27% → R@3 50%로, 맞는 자막이 2~3위에 있는 경우가 많았습니다. 순위를 다시 매기거나(re-ranking) 상위 후보를 함께 보여주는 화면이 1위 정확도를 올리는 것보다 효과가 클 수 있습니다. 번역 + Moment-DETR(a)(b)는 R@3도 12~17%로, 후보를 늘려도 낮습니다.
8. R@3·시작점은 정의(중복 후보 제외 기준 IoU 0.5, 시작 허용 ±5초)를 먼저 정하고 계산했습니다. (M1, 탐색적) 방식의 값은 같은 이유로 탐색적 결과입니다.

**다음 단계:** (1) 설명문 구간 길이 규칙(M1 등)·재순위·Whisper 모델·임베딩 모델은 dev에서만 비교해 정하고 test로 확인 ([embedding_compare.md](embedding_compare.md)), (2) 추가한 말 내용 S 질의(AI 초안 28개) 검수, (3) 정답 없음 질의 12개로 점수 임계값(결과 없음 판정) 평가.

## S 질의 편향 점검: 말 내용 vs 화면 묘사

S 질의(말로 설명되는 장면)가 실제로는 화면을 묘사하는 말투로 쓰였다면, 자막 검색(d)이 불리하고 설명문 검색(e)이 유리하게 측정될 수 있습니다. 그래서 S 질의를 두 종류로 나눠 비교했습니다.

분류 기준:

- **말 내용**: 찾는 대상이 말한 내용·말하는 행위(설명, 주장, 소개, 인사, 특정 발언)인 질의. 소리만 들어도 정답 구간을 고를 수 있다. 예: 「배터리 수명 늘리는 방법 설명」, 「잘 먹었다고 인사하는 장면」
- **화면 묘사**: 찾는 대상이 보이는 물체·동작·화면 그래픽·경기 장면인 질의. 소리를 끄고 봐도 정답 구간을 고를 수 있다. 예: 「이어팁 크기 비교하는 장면」, 「러그 까는 장면」
- 둘 다 해당하면 질의의 핵심 동사로 정함: 말하다·설명하다·소개하다·인사하다 → 말 내용, 그 밖의 동작·물체 → 화면 묘사.
- 분류는 질의 문장만 보고 했고(결과를 보기 전 기준), 질의별 분류와 이유는 [eval_v2_s_query_kinds.tsv](eval_v2_s_query_kinds.tsv)에 있습니다.

| 종류 | 질의 수 | (d) 자막 | (e) 설명문 | (e)+M1 확장 (탐색적) | 융합 A |
|---|---|---|---|---|---|
| 말 내용 | 2 | 1/2 · 1/2 · 0.38 | 0/2 · 0/2 · 0.00 | 0/2 · 0/2 · 0.00 | 1/2 · 1/2 · 0.35 |
| 화면 묘사 | 28 | 7/28 · 3/28 · 0.16 | 4/28 · 0/28 · 0.10 | 9/28 · 7/28 · 0.21 | 4/28 · 1/28 · 0.13 |

각 칸: IoU ≥ 0.3 개수 · IoU ≥ 0.5 개수 · 평균 IoU.

- **S 질의 30개 중 2개만 말 내용 질의입니다.** AI 초안 작성 지침이 S를 '말과 화면이 함께 나오는 장면'으로 정의하고 장면 묘사형 예시를 줬기 때문입니다. 지금 S 결과는 사실상 '말이 함께 나오는 장면을 화면 묘사로 찾기'의 결과입니다.
- 화면 묘사 S 28개에서도 자막 검색(d)은 IoU ≥ 0.3 기준 7개로 설명문 검색(e) 4개와 비슷했습니다. 즉 이번 데이터로는 '질의 말투가 자막 검색을 불리하게 만들었다'는 것도, 그 반대도 확인되지 않습니다.
- 말 내용 질의가 2개뿐이라 두 종류의 차이는 판단할 수 없습니다. 자막 검색이 실제로 강할 것으로 보이는 말 내용 질의(설명·주장·팁·특정 발언을 찾는 질의)를 dev·test에 각각 10개 이상 추가해야 합니다. AI 초안으로 dev 13개·test 15개를 라벨 파일에 추가했고(검수 전이라 이 문서의 수치에는 넣지 않음), 임베딩 모델 비교([embedding_compare.md](embedding_compare.md))에서 dev 13개를 참고용으로 썼습니다.

## 재현 방법

프로젝트 루트에서, 영상 12개를 `~/scenefinder_eval/videos/<YouTube ID>.mp4`에 둔 상태로 실행합니다.

    OUT=~/scenefinder_eval/results_v2_b8
    cp ~/scenefinder_eval/labels_draft.json $OUT/labels_snapshot.json
    python ai/experiments/translation_compare/captions.py --out $OUT --queries $OUT/labels_snapshot.json --variants qwen_incl   # 8장 묶음(기본)
    python ai/experiments/translation_compare/run.py --out $OUT --queries $OUT/labels_snapshot.json
    python ai/experiments/translation_compare/fusion.py --out $OUT

    # Whisper 비교: feature·설명문은 복사하고 자막만 large-v3-turbo로 다시 만듦
    W=~/scenefinder_eval/results_v2_whisper_turbo_b8; mkdir -p $W
    cp $OUT/bench_*_clip_features.pt $OUT/captions_qwen_incl.json $OUT/labels_snapshot.json $W/
    WHISPER_MODEL_SIZE=large-v3-turbo python ai/experiments/translation_compare/run.py --out $W --queries $W/labels_snapshot.json
    WHISPER_MODEL_SIZE=large-v3-turbo python ai/experiments/translation_compare/fusion.py --out $W

    python ai/experiments/translation_compare/make_report_v2.py --results $OUT --draft <검수 전 AI 초안.json> --whisper-compare $W

- 영상·feature·설명문·결과 JSON은 저장소 밖(`~/scenefinder_eval/`)에 둡니다.
- 라벨만 바뀌었으면 captions.py는 다시 돌릴 필요가 없습니다(feature·자막·설명문은 결과 폴더에 캐시됨).
