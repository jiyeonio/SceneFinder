# 사용자 과제 평가 메모 (초안, 본선 전 5명 내외)

모델 비교([vlm_model_plan.md](vlm_model_plan.md))와 별도로, 본선 전에 짧게 할 사용자 평가의 과제 문항 초안입니다. 아직 확정하지 않았습니다.

## 진행 방식 (안)

- 참가자 5명 내외, 1인당 20~25분. 가능하면 50대 이상 1~2명 포함.
- 같은 사람이 두 방식을 모두 씀: (A) YouTube에서 직접 찾기(검색·탐색바), (B) 복지바로봄. 과제 묶음 2개를 만들어 방식별로 바꿔 주고, 먼저 쓰는 방식도 사람마다 바꿈(순서 효과 줄이기).
- 과제에 쓰는 영상은 모델 평가셋 test 영상과 겹치지 않게 함(dev 또는 별도 영상).
- 기록: 과제별 완료 시간(초), 성공 여부, 이해도 문항 정답, 끝난 뒤 만족도 설문.

## 과제 문항 초안

장면 찾기 (시간·성공률):

1. 「기초연금 신청서에 무엇을 적는지 나오는 장면을 찾아 주세요.」
2. 「아이돌봄서비스를 신청할 때 내야 하는 서류가 화면에 나오는 장면을 찾아 주세요.」
3. 「청년 월세 지원을 온라인으로 신청하는 버튼을 누르는 장면을 찾아 주세요.」
4. 「국민연금 예상 수령액을 조회하는 화면을 찾아 주세요.」
5. (정답 없는 과제) 「영상에 ○○ 신청 화면이 있는지 확인해 주세요.」: 없다고 판단하기까지 걸린 시간을 봄

신청정보 이해도 (과제 뒤 바로 묻기, 객관식·단답):

1. 기초연금 신청에 필요한 서류 두 가지는?
2. 아이돌봄서비스는 어디에서 신청하나요? (온라인 사이트 / 방문 기관)
3. 청년 월세 지원 신청 자격에서 나이 기준은?

끝난 뒤 설문 (5점 척도):

- 원하는 장면을 찾기 쉬웠다 / 내용을 이해하기 쉬웠다 / 다시 쓰고 싶다
- 자유 의견: 불편했던 점

## 지표

제안서 7-라 「기대효과 검증」에 맞춤:

- 탐색 효율성: 과제별 완료 시간 중앙값 (A vs B)
- 검색 정확성: 과제 성공률
- 정보 이해도: 이해도 문항 정답률
- 이용 만족도: 설문 평균

5명이라 통계적 결론은 내지 않고, 수치와 관찰 내용을 그대로 보고합니다.
