# 평가 영상 후보

번역·융합 비교 실험([translation_compare.md](translation_compare.md))은 질의 20개, 영상 4개 규모라 방식 간 차이가 1~2건이었습니다.
평가셋을 키우기 위해 로컬에 있는 영상을 정리하고, 저작권 문제가 적은 공공·교육 영상 출처를 제안합니다.
질의 라벨링은 [tools/labeler](../../tools/labeler/README.md)를 씁니다.

### 고르는 기준

- **분야를 넓히기**: 지금은 요리·운동·쇼핑·생활 4개 분야, 1분 안팎이 대부분입니다. 뉴스·브리핑, 교육(강의·실험), 관광·풍경, 스포츠를 추가합니다.
- **길이**: 1~10분. 긴 영상일수록 무작위 기준선이 낮아지고, 1위 구간 선택이 어려워집니다.
- **음성 조건**: 한국어 음성 / 음성 없음(배경음악만) / 외국어 음성을 섞어, 서비스의 두 경로(자막 검색, 영상 검색)와 (e) 설명문 검색을 모두 평가합니다.
- **규모**: S와 V가 각각 50개 이상이면, 지금처럼 1~2건 차이가 아니라 5~10건 차이로 비교할 수 있습니다. 영상당 질의 5~8개, 영상 15~20개를 목표로 합니다.
- **정답이 하나로 정해지는 장면**: 같은 동작이 여러 번 나오면 구간을 모두 표시하거나, 질의를 더 구체적으로 씁니다.

### 받은 영상 두는 곳

- `data/`는 원본 작업 폴더를 가리키는 심볼릭 링크라, 새 영상은 `data/` 아래가 아닌 별도 폴더(예: `~/scenefinder_eval/videos/`)에 둡니다. 라벨링 도구는 저장소 밖 경로를 절대 경로로 기록합니다.
- 영상은 저장소에 커밋하지 않습니다.

### 기록할 것

영상마다 라벨링 도구의 메모나 별도 목록에 남깁니다: 출처 URL, 기관·제작자, 이용 조건(공공누리 유형 / CC 라이선스 / AI Hub 데이터셋 번호), 받은 날짜.
