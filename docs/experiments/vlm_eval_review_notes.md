# AI 초안 검수 때 먼저 볼 것

초안 작성 에이전트(화면·자막을 본 AI 초안)가 남긴 메모를 정리한 것입니다.

공통: 초안 작성용 시트의 시각 표시가 실제보다 1~1.5초 빨랐습니다(발견 뒤 수정). 에이전트들은 대부분 원본 해상도 프레임이나 자막 시각으로 경계를 정했지만, **시작·끝이 1~2초 어긋난 초안이 있으면 고쳐 주세요.**

## dev
- dev01: 내레이션과 노란 자막 띠가 같은 말이라 S·V가 많이 겹침. 개인정보 동의 V(113–141.5)가 4:21–4:45의 2단계 정보제공 동의 화면과 헷갈릴 수 있음. 자막만 언급 구간 [30.2–35.5]은 화면 카드에 이미 로그인 방법이 있어 약함.
- dev02: 1355 전화번호 S 질의 구간이 약 2.6초로 짧음. 카카오페이 지문·비밀번호 V 질의는 짧은 구간 두 개.
- dev03: 「2025년 200% 확대」 V 시작 95.0초는 글자가 서서히 나타남(±1초). Whisper 「아이돌보험」=아이돌봄.
- dev04: 화면 자막이 내레이션을 그대로 보여 줘 S 정답도 화면 글자로 찾을 수 있음. Whisper 「의비나 면지역」=읍이나 면지역.
- dev05: 통장 사본 S 질의는 내레이션(첨부해야 함)과 화면 자막(약 187.5초, 10:33 무렵 「없으면 생략 가능」)이 다름. 질의를 살릴지 판단.
- dev06(말 없음): 경계는 화면 아래 자막 띠 기준(±0.5초).
- dev07: 관리비/실물카드 문구 V 구간이 김(146.1–209.6), 끝은 스크롤(±0.5초). 지원 금액 정답 없음 질의는 작은 신청서 글자를 다 읽지 않았으니 확인.
- dev08: 적용 시점 정답 없음 질의도 작은 글자 확인.

## 사용자 질문(simulated_user) dev — 정답 구간 초안에서 먼저 볼 것

정답 구간 초안은 질문을 쓴 에이전트와 다른 에이전트가 영상을 보고 정했습니다. **dev05·dev07·dev08은 에이전트가 자막 전체는 읽었지만 프레임 시트는 일부만 봤습니다**(dev05 18장 중 3장, dev07 8장 중 2장, dev08 7장 중 1장). 그래서 「정답 없음」 판정과 화면(V) 구간을 특히 확인해 주세요.

- dev01: 「나도 받을 수 있는건가」는 나이 조건(만 65세)만 나오고 소득·재산 기준은 없음 → 부분 답으로 S 23.3–30.2. 정답 없음으로 볼 수도 있음. 「엄마 대신 … 인터넷으로 신청 되나요」는 정답 없음(본인 신청만 나옴).
- dev02: 「나중에 한달에 얼마 받는지 폰으로 보여줘」는 예상연금월액 화면(V 154.5–167.5), 금액은 흐리게 가려져 있고 내레이션은 147.4–150.1에서 언급만 함.
- dev03: 「아이돌봄 신청 화면 어디서 눌러요?」를 정답 없음으로 판정(회원가입·정회원 전환 신청 화면만 있음). 정회원 전환 신청을 신청 화면으로 볼지 판단 필요.
- dev04: 「아들 자취하는데 대신 신청해줘도 되나요」는 두 구간이 서로 다른 답(월세 지원은 본인 신청, 주거급여는 가족 신청·위임장 가능). 「이거 아직 신청 되는거에요?」는 정답 없음(영상에 날짜가 없고 제목에만 마감 표시).
- dev05: 「실업급여 날짜 까먹으면 어떻게 돼」는 부분 답(정해진 실업인정일에 신청하라는 설명만 있고 놓쳤을 때 결과는 없음). 「남편 대신 …」은 정답 없음.
- dev06(말 없음): 「취준하는데 매달 돈 주는거 얼마에요」는 신청금액 50만 원 화면(매달이라는 말은 없음). 「신청하고 나서 뭐 해야 돼요」는 「신청 후 정보 다시 확인」 자막(142.5–155.0)으로 잡았지만 영상 전체를 뜻할 수도 있음.
- dev07: 「엄마 난방비 지원 인터넷으로 어떻게 신청해요」는 PC·모바일 신청 두 구간(대신 신청 내용은 없음). 「카드로 받는거에요 요금에서 빠지는거에요?」는 부분 답(실물·가상카드 선택만 나옴).
- dev08: 「아빠 통신비 할인 대신 신청하는 화면」은 정답 없음. 서비스 신청 대상자 고르는 화면(152.3–154.9)이 경계 사례라 확인.
