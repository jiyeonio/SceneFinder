## 핵심 표: 구간 검색 CLIP 버전(영어 질의) vs VLM 버전(한국어 질의), QVHighlights val

모델 구조·학습 코드·학습 영상·seed(2018)가 같고 **특징 추출기와 질의 언어만** 다릅니다. CLIP 버전은 영어만 다룰 수 있어 원래 영어 질의로, VLM 버전은 한국어 질의를 번역 없이 그대로 넣어 쟀습니다.

| | 구간 검색 CLIP 버전 | 구간 검색 VLM 버전 |
|---|---|---|
| 특징 추출기 | CLIP ViT-B/32 (영어) | Qwen3-VL-Embedding-2B (다국어) |
| 학습 질의 | 영어 | 한국어 (영어 질의 번역) |
| 평가 질의 (val 1,550개) | **영어** | **한국어** (번역 없이 입력) |
| R1@0.5 | **52.58** | **52.52** |
| R1@0.7 | 35.35 | 32.65 |
| mAP | 32.01 | 29.46 |

- VLM 버전 = 복지 dev에서 고른 「질의 토큰, 한국어만 학습」(계획대로 영어만/한국어만/영어+한국어 중 dev R@1 최고). 나머지 변형의 한국어 val R1@0.5: 영어+한국어 52.26, 영어만 51.35.
- **해석**: 한국어 질의를 번역 없이 넣어도 영어 CLIP 버전과 1위 정확도(R1@0.5)가 같은 수준입니다(차이 0.06점). 더 엄격한 R1@0.7·mAP는 2.7·2.6점 낮습니다.
- **주의(제안서에 같이 적을 것)**: ① 한국어 val 질의는 영어 질의를 기계 번역(로컬 Qwen3-VL-4B)한 것이라 사람이 쓴 한국어 질의와 분포가 다를 수 있습니다(오역 예: "military patriots"→「군사적 애국가」). ② CLIP 버전은 원래 영어 질의를 받아 유리한 조건입니다. ③ QVH는 브이로그·뉴스 영상이라, 복지 안내 영상(아래 dev 표)에서는 두 버전 모두 무작위 수준입니다.
- 같은 VLM 버전을 영어 val로 재면: 영어만 학습 55.55, 영어+한국어 52.39, 한국어만 51.74.

## 결론 (구간 검색 VLM 버전)

- QVH(학습한 종류의 영상)에서는 한국어 질의를 번역 없이 넣어도 영어 CLIP 버전과 R1@0.5가 같은 수준(52.52 vs 52.58)입니다. → 제안서의 「특징 추출기만 바꾼 VLM 버전」 비교 결과로 씁니다.
- 복지 안내 영상에서는 창 나누기·복지 데이터 추가 학습 모두 **IoU와 시작점 모두 무작위 수준**입니다(시작 ±5초 4~6%, 오차 중앙값 74~114초). 사용자 결정(2026-11-12)대로 **비교 결과로만 정리하고 시연·최종 후보에는 쓰지 않습니다.** 결합 규칙 격자에서도 가중치 0이 골라졌습니다.
- 가능한 원인(검증하지 않음): 복지 정답 구간이 짧음(중앙값 12초, QVH 짧은 구간 mAP 3.7), 학습 영상 종류(브이로그·뉴스)와 화면 구성(안내 화면·글자) 차이, 복지 학습 쌍이 적음(1,414개).
